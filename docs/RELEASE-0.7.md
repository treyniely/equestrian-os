# 0.7 — Barn team and daily tasks

Admin navigation adds Barn team: intern profiles with weekly hours/dates off, daily attendance, calendar-derived preparation tasks and manually assigned tasks. Prepare day's task plan explicitly generates one preparation task per assigned horse/mounted session, due 15 minutes before the session, without duplicate generation. The plan requires review and trainer direction/checks; it is deterministic schedule logic, not AI or a claim of horse-care judgment. Calendar suggestions are now labeled Suggest trainer & horses with a separate block explanation to prevent button/text collision.

Automatic assignment chooses an intern available at the task time and balances open task counts. Business hours and intern schedules/absence apply. Not here today reassigns only To do tasks on that day. In-progress work is retained and flagged for a deliberate handoff; completed work stays intact. Without an available intern, work remains unassigned. Manual tasks/assignments can override weekly hours, but not the Not here today flag. Assignment changes reset work to To do. Task updates use version timestamps; canceled source sessions pause their preparation tasks and reject Start/Complete operations.

Barn view at /barn is responsive for a tablet browser and refreshes every 30 seconds when visible. It is not a native App Store download, offline app, or device-managed kiosk. A new intern role has read-only Barn team access and no family/customer/billing access. Managers need intern management permission to update tasks. Sharing an owner login is not an access-control boundary; provision the restricted board role for a shared device. Private Sites access still needs its separate gate; this release does not widen the audience. Existing stored team grants default new permissions off; the owner can grant them.

Migration 0008 adds daily attendance and task tables, tenant/day indexes, unique attendance and generation keys. Domain assignment/time helpers, server barn service and reusable team board are separated. No new dependencies. Daily write queries are tenant/day scoped; broader workspace read pagination remains a future scaling improvement. Background plan generation, individual intern self-service task completion, estimated task effort/capacity, multi-shift days, recurring manual chores, native/offline support and notifications are not implemented.

Release verification: check:release passed TypeScript, 61 tests and production build. Tests cover local time conversion, retry-safe plan generation, load distribution, absence handoff, unavailable staffing, manual ownership checks, stale changes, canceled sessions and intern-role data isolation. Source spacing review covered renamed scheduling help, roster selectors, task cards, dialogs, responsive action wrapping and checkbox/calendar controls. Browser preview remains unavailable; no completed desktop/tablet visual QA or actual tablet install verification is claimed.

Rollback: retain migration 0008 tables/records; code can roll back to the immediately previous compatible release. Never reverse migrations or discard task history as part of UI rollback.
