# Release 0.18 — Actual weeks, individual days and the master calendar

The lesson editor now navigates actual Monday–Sunday date ranges inside the chosen month. Each day shows its date, actual free teaching hours, planned bookable-session count and an Add hours action. Days can have different hours and up to four morning/afternoon windows. Unscheduled dates remain explicit; staff are not asked to interpret numbered occurrence weeks. Closed dates, days off and booked times are reflected in availability.

Copy a day’s hours to the available dates in the displayed week, or repeat that week’s weekday pattern through the rest of the month. Copies are local, reversible with Undo and editable per date. Partial first/last weeks copy only the weekdays actually shown. Later custom hours for the same lesson are replaced only by the explicitly labeled Repeat action. Closed dates and recorded intern absences are skipped; copied outer bounds are narrowed to available daily hours. Internal breaks/bookings continue to be excluded by the shared slot generator.

Horses and additional trainers are removed from the scheduling editor. Supporting interns remain optional. The backend no longer requires preselected horses for mounted groups/experiences either: publish times first, assign horses after riders book. Existing horse profiles, reviewed recommendations, suitability/conflict validation for explicitly assigned horses and preparation tasks are retained. One lead trainer per schedule remains; academy-wide planning can place different lead trainers on separate schedules.

The month opens on a wide weekly calendar that shows all planned lesson/activity types alongside existing live sessions, in time order. It displays trainer names, times, session capacity and remaining spots on already-live sessions. Summary totals distinguish sessions from booking spots per academy-named offering. Add on a date starts a schedule at that calendar week; choosing the lesson pre-fills a suitable time window for that date. Planned blocks can be clicked to edit. Consecutive matching slots are grouped into readable windows with explicit session/place counts, while review retains individual sessions. Private lesson slots, groups, horsemanship classes and events share this calendar. Responsive layouts become two-column agendas and then single-day stacks on smaller screens; the modal’s fixed Back/close header remains.

Domain planning supports optional dateWindows with explicit ISO local dates and From/Until ranges. Server validation rejects outside-month/duplicate dates, invalid times and overlaps. Adjacent windows are coalesced; configured gaps carry across separate windows. Legacy recurrence/count payloads remain compatible. Reviewed snapshots, stable occurrence keys, tenant checks, resource guards and atomic retry-safe publication remain. The plan ceiling is now 200 sessions while the existing 800-write guard remains, accommodating master monthly plans with fewer horse reservations.

Architecture: one calendar-week/copy module, one combined weekly calendar component, shared free-interval and lesson-window calculations. The obsolete suggested-month-start engine and its superseded test, count-only helper and old rule-editor styles were removed. No dependencies, migrations, configuration, secrets or permissions added. Rollback: restore 0.17. Already-published sessions retain their original schema. Changes to local date-specific lesson hours do not overwrite the trainer’s saved business/profile availability rules.

Validation: TypeScript, all 130 automated tests and production build passed before publication. New coverage checks month/leap-year week boundaries, immutable copy operations, day-off skips, actual free intervals, different daily hours/split windows, mounted groups without preassigned horses, date validation, gap handling and a mixed private/group/horsemanship/event week published atomically with correct booking capacity. Existing authorization/concurrency/review-snapshot tests remain.

Source UI audit covers week arrows/date labels, per-day empty/closed states, day-window validation, copy/Undo affordances, calendar ordering/capacity labels, responsive grids and shared modal Back/close clearance. Browser screenshots, keyboard and 390/768/1440px visual QA remain unverified: the managed preview route refused connections in the most recent attempt and there is no evidence of recovery. No visual QA pass is claimed. Stripe checkout and email/SMS delivery remain unconnected; monthly announcements remain drafts.
