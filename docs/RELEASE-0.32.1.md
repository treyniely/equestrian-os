# Past events and relaunch

The offering list derives Past events from the last occurrence end time. It refreshes when the next occurrence ends while the page is open. Past events can be removed using the existing reversible archive action. Original dates and registrations remain accessible in Calendar.

Relaunch requires offering and scheduling management permissions. It publishes a new occurrence using the same offering, capacity, timing mode and time zone, keeping plan eligibility and earlier bookings. Timed events prefill the previous start and end times. The insert checks that all earlier occurrences ended and uses the existing unique request key to prevent duplicates on retry. No migration or new dependency. Browser layout and interaction remain unverified.
