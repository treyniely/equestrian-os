# Release 0.16.2 — Trainer → month → lesson times

Opening Plan a trainer’s month now shows trainer cards only, with photo/initial fallbacks and names. Selecting a trainer immediately advances to a separate month screen. Twelve matching month cards cover the next twelve full months in the academy’s local calendar, with month names and years. Selecting a month immediately opens lesson planning; neither selection screen has a Continue button, month input, mode switch or default placeholder identity panel.

The Back arrow lives in the fixed dialog header at the top left. It returns review → lesson times → months → trainers → calendar, preserving controlled lesson schedules, subject/message drafts and relevant manual date exclusions until the dialog closes. Whole-academy planning has its own Calendar action and enters at the month screen. Existing master-plan capability remains; it no longer complicates trainer selection. Escape, backdrop click and the fixed close button retain their existing behavior.

Shared Dialog gains optional backward-navigation props. Modals without these props keep their existing layout. The Back control is 44px with a destination-specific accessible label and is disabled during preview/save. Stage changes focus the new heading and reset only the dialog body scroll. Trainer/month cards are native keyboard-accessible buttons with pressed state, visible focus and one-click advancement. Month cards use three columns, two on narrow screens; trainer cards retain the established two/one-column layout. Obsolete setup/mode-switch/inline-Back styles are removed.

Architecture: isolated trainer and month picker components, one calendar-month helper. No dependencies, database migrations, permissions or configuration changes. Existing availability/conflict/booking/publication services are unchanged. Rollback: restore 0.16.1.

Validation: TypeScript, all 119 automated tests and production build passed before publication. Two new tests cover twelve consecutive months, year rollover, academy-local month boundaries and leap-year dates. Source audit covered forward/back transitions, retained values, initial empty trainer state, native button semantics, header/close clearance and responsive card widths. Managed preview restarted after checkout restoration, but its exact URL http://terminal.local:4173/ still returned net::ERR_CONNECTION_REFUSED. Browser interaction, screenshots, keyboard and 390/768/1440px visual QA remain unverified; no visual pass is claimed.
