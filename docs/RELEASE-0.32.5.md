# Event class pricing

Events can use one event price or up to 100 named, individually priced classes. An optional discounted All Classes Pass covers the full list. The academy saves pricing in existing offering details, and archived details and relaunch retain it. Families can compare selections and totals in the portal. Paid checkout and per-class registration and rosters are pending. Class-priced events cannot use ordinary online booking or be added to new plans. No schema or dependency change. Browser interaction remains unverified.
