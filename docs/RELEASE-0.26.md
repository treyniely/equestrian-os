# Release 0.26 — Rider enrollment and connected subscriptions

Academy setup now includes a dedicated Payments section using Stripe’s official wordmark. It explains connection, EO plan setup and rider subscription management. Lessons & Services adds optional offering/plan descriptions and publishes immutable monthly rider-plan versions to the connected academy Stripe account without manual duplicate product entry.

Add rider begins with an academy-specific plan or individual-offering choice. Subscription-only catalogs do not show standalone member activities. The next step collects rider details, followed by the selected plan review or a filtered calendar. The parent must approve the additional recurring cost before Stripe Checkout. Family Account and customer Manage show rider subscription states; EO controls cancellation/undo and plan changes at renewal. Stripe-hosted pages remain for secure payment-method/invoice functions, with admin dashboard links secondary.

Implemented server integration: actor-bound owner Connect OAuth; tenant-scoped catalog/Customer mappings; one pending checkout per rider; signed connected-account webhooks; canonical provider reads; unique event/invoice keys; atomic rider-specific allowance grants; frozen plan versions; future plan schedules and manual/online overlap guards. No new dependency. Detailed architecture, provider policies, secure configuration, sandbox checklist and rollback: STRIPE-BILLING.md.
